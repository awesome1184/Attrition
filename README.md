# Attrition

Static browser prototype for a strategy game.

## Current systems

- Food, Wood, Stone, Iron, Oil, Mana, and Gold.
- Settlement construction and resource production.
- Population and storage limits.
- Military training, food upkeep, power, and wounded units.
- World territories, ownership, resources, bases, armies, and claims.
- A portal PvE placeholder.
- 10-minute game ticks.
- Local browser save data.
- Debug controls.

## Information design

The interface follows three rules:

1. Names are simple and descriptive by default.
2. Flavor text is not generated by the game.
3. Mechanics are inspectable.

Relevant values are shown where they are used. Detailed screens expose costs, effects, production, unit power, upkeep, ownership, territory resources, and basic rules instead of requiring the player to infer them from prose.

Human-written names and flavor can be added later as explicit content. They are not generated from mechanics.

## Running

The project is static HTML/JavaScript and can be hosted with GitHub Pages. There is no build step or external dependency.
